# 반짝이는 주말

> 이번 주말, 우리 아이는 무엇에 눈을 반짝일까요?
> 아이 기질 리포트로 이메일 구독자를 모으는 1차 전환 페이지.

스폰지클럽 3기 2회차 과제 · 말디니(박진형)

---

## 이건 뭔가

**빌드 없는 정적 페이지입니다.** `npm install` 필요 없고, 파일 네 개가 전부예요.

```
index.html    페이지 전체 (히어로 · 고백 · 3단계 · 개인정보 · 폼 · 완료화면)
style.css     스타일
app.js        폼 검증 + 전송      ← 여기 URL 한 줄만 바꾸면 됩니다
apps-script.gs  구글 시트에 붙여넣을 코드 (배포엔 안 쓰임)
hero.jpg      히어로 사진
empty.jpg     고백 섹션 사진
```

---

## 세팅 — 딱 두 가지

### 1. 구글 시트 연결

1. [새 구글 시트](https://sheets.new) 만들기
2. **확장 프로그램 → Apps Script** → `apps-script.gs` 내용 통째로 붙여넣고 저장
3. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** ⚠️ 이거 안 바꾸면 저장이 안 됩니다
4. 승인 (*"확인되지 않은 앱"* 경고는 정상 → 고급 → 이동 → 허용)
5. 나온 `https://script.google.com/macros/s/.../exec` 주소 복사
6. **`app.js` 7번째 줄**에 붙여넣기

```js
const APPS_SCRIPT_URL = 'https://script.google.com/macros/s/여기/exec';
```

> 탭(`신청` / `관찰결과`)은 **자동으로 만들어집니다.** 미리 만들 필요 없어요.
> 코드를 고치면 **"새 배포"를 다시** 해야 반영됩니다. 저장만 하면 안 바뀝니다.

### 2. 사진 두 장

| 파일 | 무엇 | 없으면 |
|---|---|---|
| `hero.jpg` | 크레용 쥔 손 + 그림 (얼굴 없이 잘라서) | 그 자리가 자동으로 사라집니다 |
| `empty.jpg` | 아무도 타지 않은 흔들말 | 마찬가지 |

**없어도 페이지는 정상 동작합니다.** 나중에 넣으면 돼요.

## 배포 (Vercel)

빌드 설정이 필요 없습니다.

1. 이 폴더를 GitHub 저장소로 push
2. [vercel.com](https://vercel.com) → **Add New → Project** → 저장소 선택
3. Framework Preset: **Other** · Build Command: 비움 · Output Directory: 비움
4. **Deploy**

이후엔 push할 때마다 자동 배포됩니다.

## 문구를 고치고 싶으면

전부 `index.html` 안에 한글로 들어 있습니다. 찾아서 고치면 됩니다.

| 고칠 것 | 어디 |
|---|---|
| 헤드라인 | `<h1 class="hand">` |
| 고백 글 | `<section class="band">` 첫 번째 |
| 받는 것 3단계 | `<ol class="steps">` |
| 모집 기간·자격 | 맨 아래 `footer .dim` |
| 완료 화면 안내 | `<div id="done">` 안 |
