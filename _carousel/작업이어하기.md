## 2. 회사 컴퓨터에서 할 일

### 파일 받기

채팅에서 아래를 내려받아 **한 폴더에** 넣는다.

```
캐러셀_편집기.html          ← 이걸 브라우저로 연다
캐러셀_디자인시스템.md
작업이어하기.md              ← 이 문서
hero.jpg  empty.jpg  focus.jpg
```

### 편집기 쓰기

1. `캐러셀_편집기.html`을 더블클릭 (크롬 권장)
2. 회색 이미지 박스 클릭 → 오른쪽 패널에서 사진 업로드
   - 1·9장 → `hero.jpg` / 2장 → `empty.jpg` / 3장 → `focus.jpg`
3. 글자는 클릭해서 바로 고친다
4. **작업을 멈출 때는 반드시 `JSON 저장`** — 편집기는 브라우저에 아무것도 안 남긴다
5. 다시 시작할 때 `JSON 불러오기`로 이어서 한다

### 다음 결정 — 4·5·6장 이미지

세 갈래 중 하나를 고른다.

- **① 원본에서 꺼내기** — `_originals/hyoa_1~6`(집 컴퓨터에만 있음)에 안 쓴 컷이 있는지 본다. 있으면 이게 제일 낫다

## 4. 캐러셀과 별개로 남은 일

- **기질 리포트 실물이 아직 없다.** 신청이 들어와도 보낼 게 없다. 첫 발송이 금요일이라 그전에 한 명분을 뽑아봐야 한다
- **랜딩 완료화면 원고가 "3일 안에"로 되어 있다.** 과제 06에서 금요일 발송으로 바꿨으니 문구를 고쳐야 한다
- **원고의 판정 기준에 구멍이 있다.** "넷 중 셋 이상"인데 조용한 아이는 ①④ 둘만 나온다고 적혀 있다. 캐러셀에서는 "조용한 아이는 둘만으로도"로 풀었다. 랜딩 원고도 같이 고치면 좋다
- **인스타 계정 미개설.** 캐러셀은 만들어두고 계정이 열리면 첫 게시물로 올린다
